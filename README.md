Codigo relacionando a trabalhos referente a materia de inteligencia artificial.

<h3>function_AI.py</h3>

Algoritimo de IA que consiste em achar um valor mais poximo de "x1" e "x2" referente a função definida no começo do codigo  ("(x1**2 + x2 - 11) + (x1 + x2**2 - 7)**2").

<hr>
<h3>plagiarism_detector.py</h3>

Algoritimo de IA que usa a logica fuzzy para fazer uma compareção entre dois texto e aplica o "Levenshtein distance" para tentar descobrir a similaridade dos textos.

credits: @Fael123Programming

<h1>Trabalho Final</h1>
Este trabalho final consiste no trinamento de um pre-modelo de IA o Yolov8 para fazer a detecção e classificação de objetos, no caso alguns dos mobs presentes no jogo minecraft. Dentro da pasta temos 2 tipos de arquivos:<br><br>
treino_modelo.py -  responsavel por treinar nosso modelo com base em um data set contendo a imagem e as coordenadas de presença de cada mob para posterior reconhecimento.<br>
capture_windows.py - responsavel por capturar determinados frames da nossa tela (no caso a janela do jogo do minicraft) e mostrar ao lado os objetos que estão sendo detectados em tempo real.<br>
